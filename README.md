# Сектор

**Сектор** — настольная Windows-лаборатория для создания, хранения и предпросмотра собственных визуальных симуляций в эстетике 2014–2016 годов.

## Возможности версии 0.3

- Тёмный графитовый интерфейс, мягкие серые панели и оранжевая линия сверху.
- Библиотека из пяти тем: «Синий протокол», «Снежный кот», «Красный терминал», «Тихий чат» и «Янтарная панель».
- Общие анимационные эффекты с разными цветами, значками и визуальным оформлением.
- Встроенный редактор проектов: название, описание, стиль основы, метка и акцентный цвет с живым мини-просмотром.
- Проекты сохраняются в переносимый формат `.sector.json`; можно открыть их позже, продолжить редактирование и экспортировать HTML + BAT.
- Полноэкранный предпросмотр показывает имя проекта, метку и выбранный акцентный цвет.
- Предпросмотр в отдельном обычном окне. Выход доступен через Esc, кнопку и стандартный крестик.
- Импорт отдельных файлов и папок с сохранением структуры каталогов.
- История открытий и экспорт каждой темы в самостоятельную HTML-демонстрацию с BAT-запускателем.
- BAT-запускатель только открывает локальный HTML-файл в браузере. Он не исполняет импортированные сценарии и не меняет настройки Windows.

## Запуск на Windows

Нужен .NET 8 SDK.

1. Скачайте репозиторий.
2. Запустите `Собрать и запустить.bat` или выполните:

```powershell
dotnet run --project Sector/Sector.csproj
```

Сборка Release:

```powershell
dotnet publish Sector/Sector.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

## Локальные данные

`%LOCALAPPDATA%\\Sector\\`

Внутри хранятся импортированные файлы, экспорты и история. Импорт ограничен 100 МБ на файл, 300 МБ на операцию и 600 файлами.

## Важно

Это визуальные симуляции, а не настоящие блокировщики. Сектор не шифрует пользовательские данные, не блокирует ввод, не скрывает способы выхода, не добавляет автозапуск, не отключает системные средства и не запускает импортированные BAT / PS1 / Python / C# / C++ файлы. Неизвестные исполняемые файлы исследуйте только в отдельной виртуальной машине с контрольной точкой.

## Scene Editor 0.5.0

- Рабочая сцена с разрешениями 800×600, 1280×720, 1366×768, 1920×1080 и пользовательским размером.
- Добавление текстовых объектов и изображений (изображения встраиваются в файл проекта).
- Перетаскивание объектов мышью и изменение размера за нижний правый маркер.
- Слои с перемещением вверх/вниз и удалением.
- Панель свойств: имя слоя, текст, координаты, размеры, размер шрифта и цвет.
- Изменение цвета фона сцены.
- Отмена и повтор: Ctrl+Z / Ctrl+Y.
- Автосохранение в LocalAppData\\Sector\\Autosave и предложение восстановить сцену при следующем запуске.
- Переносимый формат проекта `.sector.scene.json` с проверкой данных перед открытием.


## 0.5.0 — Retro Library and Scene Editor

- Библиотека расширена до 10 самостоятельных визуальных тем 2014–2016 годов.
- Добавлены темы Green Matrix, Violet Glitch, Grey Dialog, Pixel Alert и Dark Archive.
- В предпросмотре есть необязательная озвучка через Windows SAPI; HTML-экспорт использует встроенный Speech Synthesis браузера.
- Scene Editor: сетка с переключением, масштаб 25–250%, дублирование объекта, выравнивание по центру.
- Перемещение выбранного объекта стрелками (Shift + стрелка — шаг 10 px), Ctrl+D — дублировать.
- Экспорт каждой темы остаётся локальным HTML-макетом; BAT-файл только открывает HTML в браузере.
- Все темы остаются симуляциями: без блокировки Windows, автозапуска, вмешательства в системные настройки или пользовательские файлы.
