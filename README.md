# Сектор

Windows-приложение на C# WinForms для библиотеки и безопасного предпросмотра визуальных симуляций в эстетике 2014–2016 годов.

## Возможности первой версии
- Тёмный интерфейс с оранжевой верхней полосой.
- Библиотека шаблонов.
- Импорт BAT, PowerShell, Python, C#, C++, изображений, значков, звуков и ZIP-файлов.
- Встроенный Blue Screen preview.
- Импортированные сценарии хранятся как файлы и не выполняются приложением.

## Сборка
Требуется Windows и .NET 8 SDK.

```powershell
dotnet build Sector/Sector.csproj
dotnet run --project Sector/Sector.csproj
```

Импортированные скрипты не запускаются. Для исследования неизвестных файлов используйте отдельную виртуальную машину с контрольными точками и без общих папок/буфера обмена.
